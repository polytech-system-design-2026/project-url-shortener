## Сценарии

Бэкенд-приложение по длинному URL выдаёт короткую ссылку собственного домена и по короткой ссылке делает редирект на исходный URL. Референс — Яндекс Кликер: https://clck.ru/

1. Создание ссылки. Пользователь вводит длинный URL → получает короткую ссылку вида `http://<домен>/<код>`.
2. Переход по короткой. Пользователь открывает короткую ссылку → сервис делает редирект на оригинальный URL.
3. Повторное использование. Ссылки живут бессрочно (не удаляются, не истекают) и продолжают работать после перезапуска сервиса.
4. Статистика (этап 3). Владелец ссылки узнаёт, сколько раз по ней перешли.

## Функциональные требования

- Поддержка только схем `http://` и `https://`; недопустимые входные строки отклоняются с кодом 422.
- Код ссылки — 4–10 символов `[A-Za-z0-9]`. Генерация кода без коллизий (или с корректным разрешением коллизий).
- Поведение повторного запроса «создать ту же ссылку» — на ваше усмотрение (возвратить новую короткую или ту же).
- Переход по короткой ссылке — ответ 307 с заголовком `Location`, неизвестный код — 404.
- Ссылки не теряются при перезапуске сервиса.
- Этап 3: подсчёт переходов асинхронный, через очередь; счётчик догоняет реальное число переходов не позднее чем через 5 секунд.
- Этап 3: переходы по уже известным ссылкам продолжают работать, когда PostgreSQL недоступен.

## Нефункциональные требования

- DAU (уникальных пользователей в день) — 10 000, MAU (в месяц) — 100 000.
- p95 времени ответа основного эндпоинта — меньше 100 мс.
- Доступность — 99,5 %.
- Данные не теряются при перезапуске сервиса.

Допущения для оценки: активный пользователь в среднем создаёт 1 ссылку в день и переходит по 20 коротким ссылкам; пиковая нагрузка в 5 раз выше средней; средняя длина исходного URL — 100 символов.

## Контракт API

Полная спецификация — в [`docs/openapi.yaml`](openapi.yaml), её пишете вы на этом этапе. Обязательные операции:

| Метод | Путь | Тело | Ответ | Коды |
|---|---|---|---|---|
| POST | `/links` | `{"url": "https://example.com/very/long"}` | `{"code": "Ab3dE9", "short_url": "http://localhost:8000/Ab3dE9", "url": "..."}` | 201; 422 — не http/https, не URL, пустое тело |
| GET | `/{code}` | — | редирект, заголовок `Location` = исходный URL | 307; 404 — неизвестный код |
| GET | `/links/{code}` | — | `{"code", "url", "created_at"}` | 200; 404 |
| GET | `/health` | — | `{"status": "ok"}` | 200; 503 — PostgreSQL (с этапа 3 и Redis) недоступен |

На этапе 3 добавляется:

| Метод | Путь | Ответ | Коды |
|---|---|---|---|
| GET | `/links/{code}/stats` | `{"code", "clicks": 12}` | 200; 404 |

Ошибки — JSON `{"detail": "..."}`, ошибки валидации — 422 в формате FastAPI.
